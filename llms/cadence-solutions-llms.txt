# Cadence Solutions

> Cadence Solutions, Inc. (operating as Cadence) is a New York clinical-AI and remote patient
> monitoring company. It partners with health systems and payers to manage chronic conditions
> — hypertension, type 2 diabetes, heart failure and COPD — between clinic visits, using
> FDA-cleared connected devices, a 24/7 clinical care team and supervised AI agents.
> Cadence publishes NO public developer program and NO machine-readable API contract:
> EHR interoperability (Epic, Oracle Cerner, athenahealth) is delivered as bilateral health
> system integrations, not a self-serve API. This file was generated by API Evangelist from
> the company's public surface — it is not published by Cadence.
